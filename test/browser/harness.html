          2. Code généré

          Seule la structure (types de colonnes) est garantie fidèle. Pour une colonne de formule, la formule d'origine est recopiée telle que stockée (syntaxe $Colonne de Grist) quand elle existe, sinon remplacée par la valeur par défaut du type — comme le fait Grist lui-même pour une formule vide.
